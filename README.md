# Лабораторные работы "Программирование на Python"

В данном репозитории будет готовый код, который является решением задач из лабораторных работ по предмету "Программирование на Python", который реализуется на 1 курсе ФТИ ПетрГУ.

Сначала фокус будет на том, чтобы решить только некоторые задачи и набрать минимальное необходимое кол-во баллов для того, чтобы успешно закрыть лабу, а уже потом будут добавляться решения всех остальных заданий.

Тексты заданий лабораторных работ: [Sanbox](https://edu2u.ru/sandbox/index.php/m-it/programmirovanie-na-python)

## Зависимости

В файле `requirements.txt` указаны только те библиотеки, которые необходимы для решения лабораторных.

Установить необходимые зависимости:

```bash
pip install -r requirements.txt
```
